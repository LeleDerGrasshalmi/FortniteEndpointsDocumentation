## Epic Games Store - Product Mapping

Maps a namespace to its product slug, which can be used for the [Product Page](./Product.md).

URL: https://store-content.ak.epicgames.com/api/content/productmapping \
Method: GET \
Auth Required: No

---

_Example Response (shortened)_

```json
{
  "fn": "fortnite",
  "crab": "satisfactory",
  "min": "hades",
  "ark": "ark"
}
```
