## Account Service - Get Metadata

URL: https://account-public-service-prod.ol.epicgames.com/account/api/accounts/:accountId/metadata <br/>
Method: GET <br/>
Auth Required: Yes (`account:accounts:{accountId}:metadata READ`)

## Path Parameters

`accountId`: Your Account Id

---

*Example Response*

```json
{
  "FGOnboarded": "true"
}
```
