## Redeem Web - Verify

URL: https://redeem.epicgames.com/api/code/verify <br/>
Method: POST <br/>
Auth Required: Yes

```json
{
    "code": "aaaaaaaaaaaaaaaa",
    "locale": "en-US"
}
```

## Parameters

`code`: Code to Verify <br/>
`locale`: (required) e.g. 'de' (German), fallback is 'en-US'
