## UE Marketplace - Review Delete

URL: https://www.unrealengine.com/marketplace/api/review/:offerId/reviews/:topicId <br/>
Method: DELETE <br/>
Auth Required: Yes

## Path Parameters

`offerId`: The Id of the Offer <br/>
`topicId`: The TopicId of the review

## Query Parameters

`type`: The Type of the review (reviews,questions,replies)

---

*Example Response*

```json
{
  "status": "OK",
  "data": true
}
```
