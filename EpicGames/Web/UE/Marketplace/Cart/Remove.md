## UE Marketplace - Remove Cart Item

URL: https://www.unrealengine.com/marketplace/api/shoppingCart/delete <br/>
Method: POST <br/>
Auth Required: Yes

```json
{
  "offerId": ":offer"
}
```

## Parameters

`offerId`: The Offer Id

---

*Example Response*

```json
{
  "data": true,
  "status": "OK"
}
```
