## Fortnite Website - Comp CMS

URL: https://fortnite.com/competitive/:language/api/cms/:key <br/>
Method: GET <br/>
Auth Required: No

## Path Parameters

`language`: The language or locale code. See [Languages](#languages). <br/>
`key`: The URL-encoded CMS key. See [Known Keys](#known-keys).
