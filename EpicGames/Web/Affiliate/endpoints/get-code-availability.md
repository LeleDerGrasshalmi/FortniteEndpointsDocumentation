## Get Code Availability

URL: https://sac.epicgames.com/api/get-code-availability <br/>
Method: GET <br/>
Auth Required: Yes

## Query Parameters

`code`: required SaC Code to check

---

*Example Response*

```json
{
  "data": {
    "slug": "github_lele",
    "available": true,
    "promptCRCC": false
  },
  "success": true
}
```
