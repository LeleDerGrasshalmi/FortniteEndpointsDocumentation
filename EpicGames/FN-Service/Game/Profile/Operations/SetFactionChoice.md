# SetFactionChoice

**Description**: `Set your faction choice (C7S2 - Showdown)` <br/>
**Profiles**: `athena`

## Body

```js
{
    "factionTokenTemplateId": "" // Check TemplateIds below
}
```

`factionTokenTemplateId` (the team you choose)

- `Token:athena_ch7s2_factionatoken` (Team Foundation)
- `Token:athena_ch7s2_factionbtoken` (Team Ice King)
