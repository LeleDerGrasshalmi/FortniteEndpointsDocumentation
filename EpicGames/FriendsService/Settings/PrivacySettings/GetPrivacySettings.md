## Friends Service - Get Privacy Settings

URL: https://friends-public-service-prod.ol.epicgames.com/friends/api/v1/:accountId/settings <br/>
Method: GET <br/>
Auth Required: Yes (`friends:{accountId} READ`)

## Path Parameters

`accountId`: Your Account Id

---

*Example Response*

```json
{
  "acceptInvites": "private",
  "mutualPrivacy": "ALL"
}
```
